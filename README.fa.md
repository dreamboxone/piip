# PIIP

**آی‌پی‌تی‌وی را روی رسیور ماهواره‌ای‌تان ببینید و همان لحظه به زبان خودتان بشنوید.**

PIIP یک افزونه (پلاگین) برای رسیورهای **Enigma2** است — دریم‌باکس، Vu+، زگما،
اکتاگون و دستگاه‌های مشابه. کانال‌های آی‌پی‌تی‌وی، فیلم و سریال را پخش می‌کند و
در حین پخش، صدای اصلی کانال را می‌شنود، ترجمه می‌کند و ترجمه را با صدای بلند به
**فارسی، عربی، انگلیسی یا ترکی** می‌گوید.

🇬🇧 **[English guide](README.md)** — همین راهنما به انگلیسی.

> **تا به حال با این چیزها کار نکرده‌اید؟ از اینجا شروع کنید.**
> [راهنمای گام‌به‌گام برای مبتدی‌ها](docs/fa/getting-started.md) فرض می‌کند که
> نمی‌دانید SSH چیست، تا حالا پلاگین نصب نکرده‌اید و نمی‌دانید فایل M3U چیست.
> همه‌چیز را از صفر توضیح می‌دهد.

---

## چه چیزهایی لازم دارید

| | |
|---|---|
| یک رسیور | هر رسیور Enigma2: arm64، armhf یا mipsel. یک بسته برای هر سه. |
| یک اشتراک آی‌پی‌تی‌وی | یک لینک M3U، یا حساب Xtream Codes، یا یک پورتال Stalker. |
| برنامهٔ `ffmpeg` روی رسیور | تقریباً همهٔ ایمیج‌ها از قبل دارند. |
| کلید Gemini API | فقط اگر ترجمه می‌خواهید. ساختنش رایگان است. |

ترجمه به‌صورت پیش‌فرض **خاموش** است، چون برای هر دقیقه تماشا از حساب Gemini شما
هزینه می‌شود. بقیهٔ امکانات بدون کلید هم کار می‌کنند.

## نصب در سه قدم

**۱.** فایل `enigma2-plugin-extensions-piip_1.0_all.deb` (یا `.ipk`) را از
[صفحهٔ Releases](https://github.com/dreamboxone/piip/releases) دانلود کنید.

**۲.** فایل را روی رسیور کپی و نصب کنید:

</div>

```bash
scp enigma2-plugin-extensions-piip_1.0_all.deb root@RECEIVER_IP:/tmp/
```

```bash
ssh root@RECEIVER_IP "dpkg -i /tmp/enigma2-plugin-extensions-piip_1.0_all.deb"
```

<div dir="rtl">

روی ایمیج‌هایی که به‌جای `dpkg` از `opkg` استفاده می‌کنند، فایل `.ipk` را نصب کنید:

</div>

```bash
ssh root@RECEIVER_IP "opkg install /tmp/enigma2-plugin-extensions-piip_1.0_all.ipk"
```

<div dir="rtl">

**۳.** رسیور خودش ری‌استارت می‌شود. بعد از بالا آمدن:
**Menu ← Plugins ← PIIP**

تا حالا از `scp` یا `ssh` استفاده نکرده‌اید؟
[راهنمای مبتدی‌ها](docs/fa/getting-started.md) دقیقاً می‌گوید چه چیزی تایپ کنید —
در ویندوز، مک و لینوکس.

**برای حذف:** دستور `dpkg -r enigma2-plugin-extensions-piip` (یا
`opkg remove enigma2-plugin-extensions-piip`). برای پاک‌سازی کامل
[راهنمای نصب و حذف](docs/fa/install.md) را ببینید.

## چقدر فضا و رم مصرف می‌کند؟

این اعداد روی یک رسیور واقعی **اندازه‌گیری** شده‌اند، نه تخمین:

| | |
|---|---|
| حجم دانلود | حدود ۸ مگابایت |
| فضای اشغالی روی رسیور | **۱۸ مگابایت** (۱۵ مگابایت آن تصاویر پس‌زمینه است) |
| رم هنگام گشتن در منوها | چند مگابایت داخل خود انیگما۲ |
| رم هنگام ترجمهٔ زندهٔ تلویزیون | **حدود ۱۱۵ مگابایت** روی مجموع پردازه‌های کمکی |
| رم هنگام پخش **بدون** ترجمه | حدود ۳۵ مگابایت |
| پردازنده | تصویر هرگز دوباره کدگذاری نمی‌شود، پس یک کانال ۴K بیشتر از SD هزینه ندارد |

روی رسیوری با ۲ گیگابایت رم، بیش از یک گیگابایت آزاد باقی می‌ماند.
[جزئیات کامل](docs/fa/resources.md).

## چه کارهایی می‌کند

- **ترجمهٔ زنده** صدای کانال به فارسی، عربی، انگلیسی یا ترکی، پخش‌شده روی صدای
  اصلی با دو ولوم مستقل.
- **سه نوع منبع:** پلی‌لیست M3U، حساب Xtream Codes، و پورتال Stalker.
- **فیلم و سریال** با فصل و قسمت و «ادامه از محل قطع».
- **جدول پخش (EPG)** از سرویس‌دهنده یا از فایل XMLTV، با خروجی برای EPGImport.
- **بوکه:** افزودن کانال‌های آی‌پی‌تی‌وی به لیست کانال خودِ رسیور تا با ریموت
  معمولی زپ کنید — با ترجمه یا بدون آن.
- **زیرنویس:** جست‌وجو و دانلود از OpenSubtitles و SubDL، با تنظیم زمان‌بندی.
- **۴K بدون فشار:** تصویر دست‌نخورده عبور داده می‌شود.

## حریم خصوصی و هزینه

- برنامه کاملاً روی خود رسیور اجرا می‌شود و هیچ اطلاعاتی برای ما نمی‌فرستد.
- صدای کانال **فقط وقتی ترجمه روشن است** و **فقط با کلید خودتان** به سرویس
  Gemini گوگل می‌رود.
- گوگل بابت آن صدا از حساب شما هزینه کم می‌کند. اول کوتاه امتحان کنید.
- سرور پخش محلی و resolver فقط روی `127.0.0.1` گوش می‌دهند — هیچ دستگاهی در شبکه
  به آن‌ها دسترسی ندارد.

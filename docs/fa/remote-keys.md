# کلیدهای ریموت

## در حین پخش کانال، فیلم یا قسمت سریال

| کلید | چه می‌کند |
|---|---|
| **OK** | باز کردن فهرست کانال‌ها برای پریدن به کانال دیگر بدون خروج از پخش |
| **↑ / ↓** | ولوم **صدای اصلی کانال** |
| **→ / ←** | ولوم **صدای ترجمه** |
| **قرمز** | روشن / خاموش کردن ترجمه |
| **سبز** | تغییر تأخیر (بین مقادیر موجود می‌چرخد) |
| **زرد** | ۶۰ ثانیه عقب — فقط فیلم و سریال |
| **آبی** | ۶۰ ثانیه جلو — فقط فیلم و سریال |
| **MENU** | نمایش یا پنهان کردن دستی پنل اطلاعات |
| **INFO** | وضعیت فنی: حالت موتور، بافر، نرخ داده، اتصال |
| **EXIT** | توقف پخش و بازگشت |
| **0** | روشن / خاموش کردن زیرنویس |
| **1** | جست‌وجو و دانلود زیرنویس برای چیزی که می‌بینید |
| **2 / 8** | جلو / عقب بردن زیرنویس، هر بار نیم ثانیه |
| **3** | تعویض پخش‌کننده (gstreamer ↔ exteplayer3) بدون رفتن به تنظیمات |
| **4 / 6** | تغییر نرخ فریمی که زیرنویس برایش زمان‌بندی شده |
| **5** | جدول پخش همین کانال |
| **7** | تغییر نسبت تصویر (نحوهٔ پر کردن صفحهٔ ۱۶:۹ با محتوای ۴:۳) |

### پنل اطلاعات

پنل پایین صفحه **پنج ثانیه بعد از آمدن تصویر** خودش محو می‌شود و هر کلیدی آن را
برای پنج ثانیهٔ دیگر برمی‌گرداند.

تا وقتی کانال در حال باز شدن است، یا بعد از یک مشکل در حال اتصال دوباره است،
پنل عمداً روی صفحه می‌ماند — چون تنها جایی است که می‌گوید رسیور مشغول چه کاری
است.

معنی متن وضعیت:

| متن | یعنی |
|---|---|
| `buffering... 4s` | کانال در حال باز شدن است. |
| `buffering translation... 9s` | مسیر ترجمه در حال آماده شدن است. |
| `connecting to Gemini...` | در حال تماس با سرویس ترجمه. |
| `waiting for translation...` | وصل شد؛ هنوز اولین جمله نرسیده. |
| `translation buffering...` | صدا دارد می‌رسد و با تصویر هم‌تراز می‌شود. |
| `translating` | همه‌چیز عادی است. ترجمه را می‌شنوید. |
| `playing` | پخش بدون ترجمه. |
| `stream lost - retry in 4s` | استریم قطع شد؛ برنامه خودش دارد دوباره وصل می‌شود. |

## در فهرست‌ها (کانال، فیلم، سریال)

| کلید | چه می‌کند |
|---|---|
| **OK** | باز کردن مورد انتخاب‌شده |
| **↑ / ↓** | حرکت در فهرست |
| **← / →** | صفحهٔ قبل / بعد |
| **EXIT** | بازگشت |
| **INFO** | جدول پخش، جایی که وجود دارد |

---

## در صفحهٔ اصلی برنامه

| کلید | چه می‌کند |
|---|---|
| **OK** | باز کردن بخش انتخاب‌شده |
| **← / →** | جابه‌جایی بین بخش‌ها |
| **قرمز** | بستن برنامه |
| **MENU** | سرورهای ذخیره‌شده — جابه‌جایی بین اشتراک‌ها |
| **INFO** | تنظیمات |
| **سبز** | دانلودها |

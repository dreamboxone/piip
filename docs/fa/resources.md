# فضا و حافظه

همهٔ اعداد این صفحه روی یک رسیور واقعی **اندازه‌گیری** شده‌اند — یک دستگاه با ۲
گیگابایت رم، در حال پخش یک کانال زندهٔ ۴۸۰p با ترجمهٔ فارسی روشن — نه تخمین.

---

## فضا روی رسیور

| | |
|---|---|
| حجم نصب‌شده | **۱۶ مگابایت**، در ۱۴۱ فایل |
| حجم دانلود | حدود ۱۵ مگابایت |
| محل نصب | `/usr/lib/enigma2/python/Plugins/Extensions/PIIP` |

این فضا صرف چه چیزی می‌شود:

| بخش | حجم |
|---|---|
| تصاویر — پس‌زمینه، آیکون، دکمه | ۱۵ مگابایت |
| موتور ترجمه | ۸۰۴ کیلوبایت |
| صفحه‌ها | ۷۶۴ کیلوبایت |
| ابزارهای کمکی | ۵۰۰ کیلوبایت |
| منابع (M3U، Xtream، Stalker) | ۳۲۰ کیلوبایت |
| بقیه | زیر ۵۰ کیلوبایت |

مجموعهٔ تست عمداً همراه بسته می‌رود تا بتوانید بعد از به‌روزرسانی ایمیج، سلامت
پلاگین را روی خود رسیور بررسی کنید:
`python /usr/lib/enigma2/python/Plugins/Extensions/PIIP/tests/run_all.py`

### اگر حافظهٔ داخلی رسیور کم است

تنها بخش سنگین، تصاویر است. پس‌زمینه‌ها را می‌شود پاک کرد بدون اینکه چیزی خراب
شود — صفحه‌ها به رنگ ساده برمی‌گردند:

</div>

```bash
rm /usr/lib/enigma2/python/Plugins/Extensions/PIIP/icons/bg_*.png
```

<div dir="rtl">

این کار پلاگین را به حدود ۴ مگابایت می‌رساند. با نصب یا به‌روزرسانی بعدی دوباره
برمی‌گردند.

کاور فیلم‌ها و لوگوها روی هارد ذخیره می‌شوند، نه در حافظهٔ داخلی، و مسیرشان با
گزینهٔ *Poster / Art Cache Directory* تعیین می‌شود.

---

## حافظه (رم)

خود انیگما۲ روی رسیور آزمایشی با پلاگین بارگذاری‌شده ۱۹۸ مگابایت مصرف می‌کرد.
علاوه بر آن، برنامه فقط در حین پخش چند پردازهٔ کمکی کوچک اجرا می‌کند:

| پردازه | کارش | حافظه (RSS) |
|---|---|---|
| ffmpeg (میکس) | صدای ترجمه را در استریم می‌آمیزد | ۲۲ مگابایت |
| python (کمکی صدا) | با Gemini حرف می‌زند و زمان‌بندی را نگه می‌دارد | ۲۱ مگابایت |
| ffmpeg (ضبط) | صدای کانال را بیرون می‌کشد | ۱۸ مگابایت |
| ffmpeg (منبع) | کانال را می‌گیرد و بسته‌بندی می‌کند | ۱۶ مگابایت |
| python (موتور) | مسیر را هدایت می‌کند | ۱۴ مگابایت |
| python (رله) | تأخیر ثابت تصویر را در رم نگه می‌دارد | ۱۳ مگابایت |
| python (رلهٔ HTTP) | استریم آماده را به انیگما۲ می‌دهد | ۱۰ مگابایت |

| وضعیت | حافظهٔ اضافی که برنامه می‌گیرد |
|---|---|
| پلاگین نصب است ولی باز نیست | هیچ — چیزی اجرا نمی‌شود |
| گشتن در منوها | چند مگابایت داخل خود انیگما۲ |
| پخش **بدون** ترجمه | **حدود ۳۰ مگابایت** (فقط ffmpeg منبع و موتور) |
| پخش **با** ترجمه | **حدود ۱۱۵ مگابایت** (هر هفت پردازه) |

روی رسیور آزمایشی با ۲ گیگابایت رم، در حین ترجمه ۱.۳۷ گیگابایت آزاد باقی ماند.

> **دربارهٔ این اعداد.** معیار RSS کتابخانه‌های مشترک را برای هر پردازه جداگانه
> می‌شمارد، پس مجموع واقعی کمتر از جمع ردیف‌هاست. عدد ۱۱۵ مگابایت را سقف امن
> بدانید، نه رقم دقیق.

### بافر تأخیر

بزرگ‌ترین تکه‌ی حافظه مربوط به همان تأخیری است که تصویر و صدای ترجمه را کنار هم
نگه می‌دارد: حدود ۱۲ ثانیه از استریم کانال که پردازهٔ رله در رم نگه می‌دارد. با
نرخ معمول ۱.۲ مگابیت بر ثانیه این زیر ۲ مگابایت است؛ روی کانال HD پرحجم بزرگ‌تر
می‌شود — و همین یکی از دلایلی است که *Stream bitrate while translating*
به‌صورت پیش‌فرض روی ۳ مگابیت بر ثانیه است.

---

## پردازنده

تصویر **کپی می‌شود، هرگز دوباره کدگذاری نمی‌شود**. فقط صدا پردازش می‌شود. برای
همین یک کانال ۴K بیشتر از یک کانال معمولی برای رسیور هزینه ندارد، و یک دستگاه
قدیمی می‌تواند کانال‌هایی را پخش کند که هرگز توان ترنسکد کردنشان را ندارد.

## شبکه

| | |
|---|---|
| ورودی | هر چه کانال لازم دارد، معمولاً ۱ تا ۳ مگابیت بر ثانیه |
| خروجی به Gemini | حدود ۲۵۶ کیلوبیت بر ثانیه در حین ترجمه (صدای مونو ۱۶ کیلوهرتز) |
| ورودی از Gemini | حدود ۳۸۴ کیلوبیت بر ثانیه صدای ترجمه |

اینترنت ۲ مگابیت بر ثانیه برای یک کانال ۴۸۰p با ترجمه کافی است. برای کانال‌های
HD، نرخ خود کانال به‌اضافهٔ حدود ۱ مگابیت بر ثانیه را در نظر بگیرید.

## چطور خودتان اندازه بگیرید

با SSH وصل شوید و این‌ها را اجرا کنید:

</div>

```bash
du -sh /usr/lib/enigma2/python/Plugins/Extensions/PIIP
```

```bash
free -m
```

```bash
ps w | grep -E "PIIP|ffmpeg" | grep -v grep
```

<div dir="rtl">

برای دیدن حافظهٔ یک پردازه، شمارهٔ آن را از ستون اول `ps w` بردارید و بنویسید
`grep VmRSS /proc/<شماره>/status`.

# توضیح تک‌تک تنظیمات

تنظیمات را با **PIIP ← دکمهٔ INFO** باز کنید.

با `↑` و `↓` جابه‌جا شوید، با `←` و `→` مقدار را عوض کنید و برای ذخیره دکمهٔ
**سبز** را بزنید. تا وقتی سبز را نزنید هیچ‌چیز ذخیره نمی‌شود.

فهرست زیر دقیقاً به همان ترتیبِ خودِ صفحه است.

---

## گروه اول — فایل‌ها، زیرنویس و فهرست‌ها

### OpenSubtitles API Key
کلید جست‌وجوی زیرنویس در سایت OpenSubtitles.
کلید رایگان را از <https://www.opensubtitles.com/consumers> بگیرید (ثبت‌نام
کنید و بعد *New consumer*). اگر زیرنویس از آنجا نمی‌خواهید خالی بگذارید.

### Download / Subtitle Directory
محل ذخیرهٔ فیلم‌های دانلودشده و فایل‌های زیرنویس.
**پیش‌فرض:** `/media/hdd/movie/`
حتماً روی هارد یا فلش باشد، نه روی حافظهٔ داخلی رسیور — حافظهٔ داخلی کوچک است و
با نوشتن زیاد خراب می‌شود.

### Poster / Art Cache Directory
محل نگهداری کاور فیلم‌ها و لوگوی کانال‌ها تا هر بار دوباره دانلود نشوند.
**پیش‌فرض:** `/media/hdd/.piip_cache/`
هر وقت خواستید می‌توانید دستی پاکش کنید؛ دوباره پر می‌شود.

### Subtitle Position
جای زیرنویس روی صفحه: **Bottom** (پایین)، **Middle** (وسط) یا **Top** (بالا).
**پیش‌فرض:** پایین. اگر تلویزیونتان پایین تصویر را می‌بُرد، بالا را انتخاب کنید.

### Subtitle Size
اندازهٔ زیرنویس: **Small**، **Medium**، **Large** یا **Extra large**.
**پیش‌فرض:** Medium. روی تلویزیون بزرگ یا اگر دور می‌نشینید، Large بهتر است.

### Subtitle Color
رنگ زیرنویس: **White** (سفید)، **Yellow** (زرد) یا **Green** (سبز).
**پیش‌فرض:** سفید. زرد روی تصویر روشن خواناتر است.

### Default VOD Stream Type
اینکه انیگما۲ برای فیلم و سریال از کدام پخش‌کنندهٔ داخلی استفاده کند. وقتی چیزی
پخش نمی‌شود، مفیدترین تنظیم همین است.

| مقدار | چه وقت |
|---|---|
| `4097 (gstreamer)` | پیش‌فرض. روی بیشتر ایمیج‌ها کار می‌کند. |
| `5002 (exteplayer3)` | اگر پخش شروع نشد یا تصویر می‌پرید، اول این را امتحان کنید. روی DreamOS معمولاً بهترین است. |
| `8193 (ServiceURL)` | کمیاب؛ بعضی ایمیج‌ها برای لینک‌های HTTPS لازم دارند. |
| `8197 (widevine)` | فقط برای محتوای دارای DRM. |

### Show +18 Adult Content
اینکه دسته‌هایی که سرویس‌دهنده «بزرگسال» علامت زده در فهرست‌ها دیده شوند یا نه.
**پیش‌فرض:** خیر.

### Items per Page (Poster Count)
تعداد فیلم یا سریال در هر صفحه: ۱۰، ۲۰، ۳۰، ۴۰ یا ۵۰.
**پیش‌فرض:** ۲۰. عدد کمتر روی رسیور قدیمی‌تر سریع‌تر حس می‌شود، چون کاورهای کمتری
هم‌زمان دانلود می‌شوند.

### VOD/Series Skin Style
شکل نمایش فیلم و سریال:

| مقدار | چه شکلی |
|---|---|
| `Default` | فهرست ساده. سریع‌ترین. |
| `Hybrid carousel` | ردیف کشویی از کاورها. |
| `Cover collection` | جدولی از کاورها. |
| `2D cover collection` | جدول ساده و سبک‌تر برای رسیور. |

## PIIP extras

### SubDL API key
منبع دوم زیرنویس. مفید است چون اغلب زیرنویس فارسی دارد که OpenSubtitles ندارد.
کلید رایگان از <https://subdl.com>.

### Subtitle Language
زبانی که زیرنویس برایش جست‌وجو می‌شود: **فارسی**، **عربی**، **انگلیسی** یا
**ترکی**.
**پیش‌فرض:** فارسی.

### TMDB API key
اختیاری. با کلیدی از <https://www.themoviedb.org/settings/api> برنامه می‌تواند
برای فیلم‌هایی که سرویس‌دهنده‌تان کاور و توضیح ندارد، پوستر و خلاصهٔ درست نشان
دهد.

### WebIF port
پورت صفحهٔ وب کوچک داخلی برای مدیریت برنامه از مرورگر.
**پیش‌فرض:** `8914`. فقط اگر برنامهٔ دیگری روی رسیور همین عدد را گرفته عوضش کنید.

## Guide (جدول پخش)

### Guide enabled
اینکه جدول پخش (در حال پخش / بعدی) نشان داده و به‌روز نگه داشته شود.
**پیش‌فرض:** بله. خاموش کردنش روی خط اینترنت کند، کمی حافظه و ترافیک صرفه‌جویی
می‌کند.

### XMLTV URL
فقط برای پلی‌لیست‌های M3U لازم است که خودشان اطلاعات جدول پخش ندارند. آدرس فایل
XMLTV را که سرویس‌دهنده داده اینجا بگذارید. در غیر این صورت خالی بگذارید — منابع
Xtream و Stalker همیشه جدول پخش خودشان را می‌آورند.

## Stalker portals

### Portal list URL
آدرسی که دکمهٔ **LOAD ONLINE** در صفحهٔ Stalker، فهرست پورتال‌های عمومی را از
آنجا می‌گیرد. بیشتر کاربران هرگز به آن دست نمی‌زنند.
**پیش‌فرض:** `https://satelliweb.gt.tc/stalker_list.log`

## بوکه

«بوکه» یعنی فهرست کانال داخل خودِ رسیور. با انتقال کانال‌های آی‌پی‌تی‌وی به یک
بوکه می‌توانید با ریموت معمولی — کنار کانال‌های ماهواره‌ای و بدون باز کردن
برنامه — رویشان زپ کنید.

### Translated audio in bouquets
اینکه کانال‌هایی که از بوکه زپ می‌شوند ترجمهٔ زنده داشته باشند یا نه.

| مقدار | نتیجه |
|---|---|
| خیر (پیش‌فرض) | زپ آنی است. ترجمه‌ای در کار نیست. |
| بله | هر زپ مسیر ترجمه را راه می‌اندازد و چند ثانیه بیشتر طول می‌کشد تا تصویر بیاید. |

### Resolver port
پورتی که کمک‌کنندهٔ داخلی — همان که ورودی بوکه را به استریم واقعی تبدیل می‌کند —
روی `127.0.0.1` به آن گوش می‌دهد.
**پیش‌فرض:** `8913`. فقط وقتی عوضش کنید که با پلاگین دیگری تداخل داشته باشد؛
مثلاً HybridIPTV از `8903` استفاده می‌کند.

## Advanced (پیشرفته)

بیشتر کاربران هرگز به این گروه نیاز ندارند. هر بار فقط یک چیز را عوض کنید.

### Default Live Stream Type
همان انتخاب *Default VOD Stream Type*، ولی برای کانال‌های زنده.
**پیش‌فرض:** `4097 (gstreamer)`. اگر کانال زنده شروع نمی‌شود،
`5002 (exteplayer3)` را امتحان کنید.

### ffmpeg
دستوری که برای اجرای ffmpeg استفاده می‌شود.
**پیش‌فرض:** `ffmpeg`. فقط اگر برنامه گفت پیدایش نمی‌کند، مسیر کامل مثل
`/usr/bin/ffmpeg` بگذارید.

### Local stream port
پورتی که برنامه روی `127.0.0.1` استریم آماده‌شده را به انیگما۲ تحویل می‌دهد.
**پیش‌فرض:** `8901`.

### Control port
پورتی که صفحه‌های برنامه روی `127.0.0.1` با موتور پخش حرف می‌زنند.
**پیش‌فرض:** `8902`.

### User agent
نامی که برنامه هنگام درخواست استریم به سرویس‌دهنده معرفی می‌کند. بعضی
سرویس‌دهنده‌ها هر چیزی را که شبیه پخش‌کنندهٔ معمولی نباشد بلاک می‌کنند.
**پیش‌فرض:** یک شناسهٔ Qt/WebKit که اکثر سرویس‌دهنده‌ها قبول می‌کنند. فقط اگر
سرویس‌دهنده گفت عوضش کنید.

## Translation (ترجمه)

مهم‌ترین گروه برای کیفیت ترجمه همین است.

### Translation enabled
کلید اصلی ترجمه.
**پیش‌فرض:** خیر — چون ترجمه برای هر دقیقه تماشا هزینه دارد. در حین تماشا هم با
دکمهٔ **قرمز** روشن و خاموش می‌شود.

### API key
کلید Gemini شما، اگر ترجیح می‌دهید به‌جای فایل اینجا تایپش کنید.

**فایل ارجح است.** برنامه به این ترتیب می‌گردد و اولین موردی را که پیدا کند
استفاده می‌کند:

۱. متغیر محیطی `GEMINI_API_KEY`
۲. `/root/apikey.txt`
۳. `/etc/enigma2/piip_apikey.txt` — با نصب مجدد پلاگین پاک نمی‌شود
۴. `apikey.txt` کنار پوشهٔ پلاگین
۵. همین فیلد

فاصله، گیومه و پایان‌خط ویندوزی خودکار حذف می‌شوند. کلید هرگز به‌طور کامل روی
صفحه، در لاگ یا در فهرست پردازه‌ها چاپ نمی‌شود.

### Model override
خالی بگذارید. برنامه از `gemini-3.5-live-translate-preview` استفاده می‌کند که
مدل ساخته‌شده برای ترجمهٔ گفتار به گفتار است. این فیلد هست تا اگر روزی مدل
تازه‌تری آمد، بدون به‌روزرسانی پلاگین بتوانید از آن استفاده کنید.

### Target language
زبانی که می‌خواهید بشنوید: **فارسی**، **عربی**، **انگلیسی** یا **ترکی**.
**پیش‌فرض:** فارسی.

### Delay (تأخیر)
اینکه تصویر چند ثانیه نگه داشته شود تا صدای ترجمه به آن برسد.
**بازه:** ۱ تا ۱۲. **پیش‌فرض:** ۶.

این عدد یک **کف** است. برنامه هنگام شروع پخش، رفت‌وبرگشت واقعی را اندازه می‌گیرد
و روی چیزی که واقعاً لازم است می‌نشیند — معمولاً حدود ۱۲ ثانیه. عدد بزرگ‌تر روی
اینترنت کند امن‌تر است؛ عدد کوچک‌تر شما را به پخش زنده نزدیک‌تر می‌کند ولی خطر
قطع شدن ترجمه دارد.

در حین تماشا هم با دکمهٔ **سبز** قابل تغییر است.

### Max backlog (بیشترین عقب‌افتادگی)
اینکه ترجمه حداکثر چند ثانیه اجازه دارد از تصویر عقب بیفتد، پیش از آنکه برنامه
دخالت کند.
**بازه:** ۲ تا ۲۰. **پیش‌فرض:** ۶.

**چرا چنین چیزی لازم است.** موتور ترجمه کندتر از گفتار متراکم زنده حرف می‌زند،
پس روی کانال پرحرف هر دقیقه بیشتر عقب می‌افتد — بعد از پنج دقیقه ممکن است ترجمهٔ
صحنه‌ای را بشنوید که تمام شده است. برنامه این فاصله را اندازه می‌گیرد و برای
لحظه‌ای تغذیهٔ صدا را قطع می‌کند تا موتور به تصویر برسد.

بهایش این است که هر بار یکی‑دو جمله ترجمه نمی‌شود. عدد کوچک‌تر ترجمه را
چسبیده‌تر به تصویر نگه می‌دارد ولی بیشتر جا می‌اندازد؛ عدد بزرگ‌تر بیشتر ترجمه
می‌کند ولی بیشتر عقب می‌افتد.

### Stream bitrate while translating
خیلی از کانال‌های آی‌پی‌تی‌وی همان برنامه را در چند کیفیت پخش می‌کنند. برنامه
می‌تواند حین ترجمه کیفیت سبک‌تری بخواهد تا رسیور عقب نماند.

| مقدار | یعنی |
|---|---|
| `Automatic (best)` | همیشه بالاترین کیفیت موجود. |
| `1.5 Mbit/s` | امن‌ترین روی خط کند. |
| `3 Mbit/s` | **پیش‌فرض.** روی رسیور واقعی بهترین تعادل اندازه‌گیری شد. |
| `5 Mbit/s` | فقط روی خط سریع و رسیور قوی. |

این فقط روی کانال‌هایی اثر دارد که واقعاً چند کیفیت ارائه می‌دهند؛ بقیه همان‌طور
که هستند پخش می‌شوند.

### Channel volume (ولوم کانال)
بلندی **صدای اصلی** کانال در زیر ترجمه، بر حسب درصد.
**بازه:** ۰ تا ۱۰۰. **پیش‌فرض:** ۳۰.

صفر یعنی صدای اصلی کاملاً قطع. مقدار بالای ۱۰۰ وجود ندارد چون فقط صدا را خراب
می‌کند.

### Translation volume (ولوم ترجمه)
بلندی **صدای ترجمه**، بر حسب درصد.
**بازه:** ۰ تا ۱۰۰. **پیش‌فرض:** ۱۰۰.

هر دو ولوم در حین تماشا با کلیدهای جهت فوری تغییر می‌کنند.

## تنظیماتی که در این صفحه نیستند

### اشتراک شما
از منوی اصلی برنامه انتخاب می‌شود (**Xtream Codes**، **M3U Playlist**،
**Stalker Portal**) و در فهرست سرورهای ذخیره‌شده می‌ماند، طوری که می‌توانید چند
اشتراک داشته باشید و با دکمهٔ **MENU** بینشان جابه‌جا شوید.

### زمان‌بندی زیرنویس
در حین تماشا تنظیم می‌شود، نه اینجا — کلیدهای `2` و `8` زیرنویس را جلو و عقب
می‌برند و کلیدهای `4` و `6` نرخ فریمی را که زیرنویس برایش ساخته شده عوض می‌کنند.
[کلیدهای ریموت](remote-keys.md) را ببینید.

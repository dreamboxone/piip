# PIIP

پخش‌کنندهٔ IPTV برای گیرنده‌های **Enigma2** با **ترجمهٔ زندهٔ صدای کانال به فارسی**.

**Routekernel** · [تلگرام](https://t.me/routekernel1) · [یوتیوب](https://youtube.com/@routekernel) · [گیت‌هاب](https://github.com/dreamboxone/piip)

---

## این برنامه چه می‌کند

هر کانال، فیلم یا سریال IPTV را پخش می‌کند و **همزمان صدایش را به فارسی ترجمه
می‌کند**. صدای اصلی و صدای ترجمه با دو ولوم مستقل کنار هم پخش می‌شوند.

ویدیو **هرگز رمزگذاری مجدد نمی‌شود** — فقط صدا پردازش می‌شود. برای همین بار روی
گیرنده مستقل از کیفیت تصویر است و یک کانال ۴K مثل SD پخش می‌شود.

---

## قابلیت‌ها

- **ترجمهٔ زندهٔ فارسی** با Gemini، با تأخیر قابل‌تنظیم (۱ تا ۱۲ ثانیه)
- **دو ولوم مستقل** برای صدای کانال و صدای ترجمه، با تغییر آنی
- **سه نوع منبع:** M3U، Xtream Codes، و Stalker (پورتال با مک‌آدرس)
- **کانال زنده، فیلم و سریال** با فصل و قسمت
- **ادامه از محل قطع** برای فیلم و سریال، با نمایش درصد پیشرفت
- **جدول پخش (EPG)** از Xtream، Stalker یا فایل XMLTV؛ با خروجی به EPGImport
- **بوکه:** افزودن کانال‌ها به لیست خودِ گیرنده برای زپ با ریموت — با ترجمه یا بدون آن
- **زیرنویس:** جست‌وجو و دانلود از OpenSubtitles و SubDL، با همگام‌سازی
- **۴K** بدون فشار روی پردازنده

## پیش‌نیازها

| نیاز | توضیح |
|---|---|
| گیرندهٔ Enigma2 | arm64، armhf یا mipsel — بسته روی هر سه نصب می‌شود |
| پایتون ۲.۷ یا ۳.x | هر دو پشتیبانی می‌شوند |
| `ffmpeg` روی گیرنده | برای دیکد صدا و پخش لازم است |
| `audioop` یا `numpy` | برای میکس صدا (`audioop` در پایتون ۲.۷ و تا ۳.۱۲ داخل خود پایتون هست) |
| کلید Gemini API | برای ترجمه؛ بدون آن فقط پخش کار می‌کند |

بعد از نصب، از منوی پلاگین گزینهٔ **Check receiver requirements** همهٔ اینها را
یکجا بررسی می‌کند. **قبل از هر کار دیگری این را بزنید.**

## نصب

**۱. بسته را در `/tmp` گیرنده کپی کنید** (با SCP یا FTP):

```bash
scp enigma2-plugin-extensions-piip_1.0_all.deb root@RECEIVER:/tmp/
```

**۲. نصب کنید** (از طریق SSH یا Telnet):

```bash
dpkg -i /tmp/enigma2-plugin-extensions-piip_1.0_all.deb
```

اگر گیرنده `opkg` دارد و `dpkg` ندارد:

```bash
opkg install /tmp/enigma2-plugin-extensions-piip_1.0_all.ipk
```

**۳. کلید Gemini را بگذارید** (فقط برای ترجمه لازم است):

```bash
echo 'YOUR_GEMINI_KEY' > /root/apikey.txt && chmod 600 /root/apikey.txt
```

کلید را از <https://aistudio.google.com/apikey> بگیرید.

**۴. تمام.** نصب‌کننده خودش انیگما۲ را ری‌استارت می‌کند و فایل `.deb` را از
`/tmp` پاک می‌کند. در ترمینال پیام می‌دهد و ۳ ثانیه بعد ری‌استارت می‌شود.

سپس: **Menu → Plugins → PIIP**

## کجا دنبال کلید می‌گردد

اولین موردی که پیدا شود استفاده می‌شود:

| ترتیب | محل |
|---|---|
| ۱ | متغیر محیطی `GEMINI_API_KEY` |
| ۲ | `/root/apikey.txt` |
| ۳ | `/etc/enigma2/piip_apikey.txt` (با نصب مجدد پاک نمی‌شود) |
| ۴ | `apikey.txt` کنار پوشهٔ پلاگین |
| ۵ | فیلد API key در تنظیمات |

فاصله، گیومه، پایان‌خط ویندوزی و BOM خودکار حذف می‌شوند. کلید هرگز کامل در رابط
کاربری یا لاگ چاپ نمی‌شود و در خروجی `ps` هم دیده نمی‌شود.

## چند پلی‌لیست با فایل m3u.txt

به‌جای وارد کردن یک آدرس در تنظیمات، می‌توانید هر تعداد پلی‌لیست را در یک فایل
متنی بگذارید. پلاگین هنگام نصب یا اولین اجرا، فقط وقتی هیچ فهرستی در مسیرهای
پشتیبانی‌شده وجود نداشته باشد، فایل نمونه را می‌سازد. فایل موجود را حذف یا
جایگزین نمی‌کند. در DreamOS مسیر معمول `/root/m3u.txt` و در بعضی ایمیج‌های
OE-Alliance مسیر `/home/root/m3u.txt` است؛ مسیرهای جایگزین زیر هم بررسی می‌شوند.

هر خط یک پلی‌لیست:

```
# خطوطی که با # شروع شوند نادیده گرفته می‌شوند
http://provider.tv/get.php?username=USER&password=PASS&type=m3u_plus
ورزشی = http://another.tv/playlist.m3u
/media/hdd/local.m3u
```

با `نام = آدرس` می‌توانید به هر پلی‌لیست اسم بدهید. وقتی بیش از یکی باشد، نام
پلی‌لیست جلوی نام گروه می‌آید (مثل `ورزشی / Sport`) تا معلوم باشد هر کانال از
کجا آمده. مسیر فایل محلی هم به‌جای آدرس اینترنتی قبول است.

آدرسی که در **Settings** وارد کنید هم کنار اینها بارگذاری می‌شود — هر دو با هم
کار می‌کنند. اگر یکی از پلی‌لیست‌ها خراب باشد بقیه بارگذاری می‌شوند و فقط همان
یکی گزارش می‌شود.

فایل در این مسیرها گشته می‌شود (اولی که پیدا شود):
`/root/m3u.txt` · `/home/root/m3u.txt` · `/etc/enigma2/piip_m3u.txt` · `/media/hdd/m3u.txt`

## استفاده

۱. **Settings** را باز کنید و منبع خود را وارد کنید (M3U، Xtream یا Stalker).
۲. به **Live channels**، **Movies** یا **Series** بروید.
۳. هنگام پخش:

| کلید | کار |
|---|---|
| `OK` | نمایش/پنهان‌کردن پنل |
| `→` / `←` | ولوم **ترجمه** |
| `↑` / `↓` | ولوم **کانال** |
| قرمز | قطع/وصل ترجمه |
| سبز | تغییر تأخیر |
| زرد / آبی | عقب/جلو ۶۰ ثانیه (فیلم و سریال) |
| `2` | جست‌وجوی زیرنویس |
| `0` | زیرنویس روشن/خاموش |
| `1` / `3` | همگام‌سازی زیرنویس |
| `5` | جدول پخش کانال |
| INFO | وضعیت فنی |
| EXIT | توقف |

### بوکه

از منوی **Bouquets** کانال‌ها را به لیست خودِ گیرنده اضافه کنید تا با ریموت زپ
کنید. اگر «Translated audio in bouquets» روشن باشد، زپ معمولی هم صدای فارسی
می‌دهد. از همین منو می‌توانید جدول پخش را به **EPGImport** بدهید.

---

## حذف

```bash
dpkg -r enigma2-plugin-extensions-piip
```

یا:

```bash
opkg remove enigma2-plugin-extensions-piip
```

**پاک‌سازی کامل** (بوکه‌ها و تنظیمات که هنگام حذف باقی می‌مانند):

```bash
rm -f /etc/enigma2/userbouquet.piip_*.tv /etc/enigma2/piip_*.json /etc/epgimport/piip.*
```

سپس گیرنده را ری‌استارت کنید.

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| پخش شروع نمی‌شود | در Settings مقدار **Service type** را روی `5002` (exteplayer3) بگذارید |
| ترجمه نمی‌آید | کلید API را بررسی کنید؛ **Check receiver requirements** را بزنید |
| ترجمه دیر می‌رسد | با کلید سبز تأخیر را زیاد کنید |
| ترجمهٔ فارسی مربوط به چند دقیقه قبل است | خودبه‌خود اصلاح می‌شود: هر ۶۰ ثانیه تغذیهٔ صدا کوتاه قطع می‌شود تا مدل به تصویر برسد. در این فاصله یکی‑دو جمله ترجمه نمی‌شود |
| لب‌خوانی جابه‌جاست | تأخیر را یکی‑دو ثانیه تغییر دهید |
| بوکه پخش نمی‌شود | انیگما۲ ری‌استارت شده؟ منوی Bouquets وضعیت resolver را نشان می‌دهد |
| پلی‌لیست بارگذاری نمی‌شود | از منوی اصلی **Test playlists** را بزنید: آدرس هر پلی‌لیست (با رمز پنهان)، کد HTTP و متن پاسخ سرور را نشان می‌دهد |
| `HTTP 403` روی پلی‌لیست | سرور شما را بلاک کرده. برنامه خودکار با UA پخش‌کننده (VLC و…) دوباره امتحان می‌کند؛ اگر باز هم ۴۰۳ داد، آدرس را در مرورگر تست کنید |
| `HTTP 401` | نام کاربری یا رمز اشتراک اشتباه است |
| `HTTP 404` | آدرس پلی‌لیست غلط است |
| `HTTP 429` | سرور موقتاً محدودتان کرده؛ کمی بعد امتحان کنید |

**لاگ‌ها:** `/tmp/piip_engine.log` · `/tmp/piip_resolver.log` · `/tmp/piip_ui.log`

## نکات

- **هزینه:** استریم پیوستهٔ صدا به Gemini رایگان نیست. اول کوتاه امتحان کنید.
- **حریم خصوصی:** برنامه روی خودِ گیرنده اجرا می‌شود، تله‌متری نمی‌فرستد، و صدا فقط
  هنگام فعال بودن ترجمه و با کلید خودتان به سرویس ترجمه می‌رود.
- **پورت‌ها:** سرور استریم و resolver فقط روی `127.0.0.1` گوش می‌دهند.
